# 深色主题反转雾优先明度阶梯，Verified 仍退化为背景

雾图在系统偏好深色时自动切换为深色主题（不提供手动切换），画布沿用 README 视觉稿的 `#0E1A2B`。ADR-0001 的核心是“已验证区域退化为背景、未验证程度靠明度差编码、唯一高饱和色留给 `Fog Returned`”，而不是那组浅色色值本身；因此深色主题反转明度阶梯：`Verified` 贴近画布（`#15243A`），`Weak Evidence` 为暗石板蓝（`#2F4868`），`Self-proof Fog` 为中明度斜纹（`#6E88AA` / `#89A0BE`），`Fog` 最亮（`#C3D0E0`，像深色背景上的雾），`Fog Returned` 改用更亮的互补橙 `#FF8A3D` 并保留 `RETURNED` 标签。实现可微调色值，但五态的明度顺序与“全画面唯一高饱和色”两条约束不可破坏；浅色主题继续以 ADR-0001 为准。

## Considered Options

- **沿用浅色色值（与 README 五态示意图一致）**：`Verified` 在深色画布上成为最亮的色块，大面积已验证代码反而最抢眼，违背 90-8-2 面积法则。README 示意图是图例，可以保留，但雾图不照搬。
- **只做浅色主题**：README 与雾图的视觉语言继续割裂，且深色系统偏好下整页高亮背景刺眼。
