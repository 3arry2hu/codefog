# 变异杀死不能单独离开自证雾

自证雾会在变异体全部被杀死后升为已验证。实现与结果断言若共享同一个错误理解，变异体仍会被杀死，预期冲突就会从雾图上消失。我们决定不新增第六种证据状态：预期冲突保持自证雾。离开自证雾除了既有的执行、结果断言、分支与新鲜度条件外，还要求结果断言早于实现，或与一份不同提交的独立预期或历史缺陷一致。`agentReady` 对自证雾和预期冲突为 false，Agent 不得把断言字面量改写成当前返回值。

## Considered Options

- **第六态并用警示橙**：预期冲突和回雾抢同一个唯一警示色，与 ADR-0001 冲突。
- **只看变异得分**：无法区分错误断言和有效断言。

## Consequences

- 没有独立预期时，同一次提交里写出的正确测试也会留在自证雾，直到另一次提交确认预期。
- `--fail-on contested` 只在断言与清单矛盾时失败。单纯的自证雾不触发它。
